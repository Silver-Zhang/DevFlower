## 新手风险

以下是需要通过任务验证的风险。C 基线审计与 A 源码审查均发现这些交接点需要更直接的提示。

1. 识别允许打开的项目目录及工作空间范围。
2. 从空白画布决定先创建配置还是先加节点。
3. 找到 CLI 发现入口，辨认安装、认证和目录状态。
4. 理解模型、Profile、推理强度和执行权限各自的作用。
5. 找到 Skills 与三段 Prompt，确认它们属于哪个 Agent。
6. 根据端口方向设置连线及上下游交接字段。
7. 理解运行前检查和禁用原因，保存后找到启动入口。
8. 找到真实结果、工具活动、发送内容和连线数据。
9. 区分取消、重读、恢复及状态待核验，避免重复发送。
10. 关闭或重启后找到草稿、历史运行和原生会话。

依次验收工作台与画布、Agent 与运行检查器、会话/助手/Git。随后固定候选执行新手任务、跨模块回归及架构实测。全部源码候选在 `v2/parity-integration` 形成。
