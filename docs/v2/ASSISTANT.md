# V2 AI 助手

打开获准的工作空间，再从工作台进入 **AI 助手**。浅色和深色共用相同的操作。

## 配置与发送

在 **助手模型设置** 选择 Codex CLI 或 Claude Code。刷新目录后选择 CLI 报告的模型与强度，或沿用本机默认。选择器只列出本机默认 HOME 与服务启动时已登记的原生 Profile 或独立 HOME。助手偏好按工作空间保存，登录与服务地址由原生 CLI 管理。

**测试真实推理** 会先显示发送预览，确认后才发起一次实际调用。安装版本、认证来源、发现目录与推理回执分别显示。CLI 未返回实际模型身份时，回执保留未报告状态。选择已保存 Agent 身份时固定其配置版本，并使用其角色、背景及提示词。助手每次调用使用自己的无工具权限。

## 对话与项目理解

在发送预览检查所选草稿、源码片段、运行与历史对话。源码查询沿用工作区文件策略，按有界目录和文本预算返回文件或符号命中。将需要的文件加入本次上下文，确认路径和行号后再发送。路径保护、忽略规则、文件类型及链接边界对搜索和预览同时生效。

发送意图及其原生回执保存在当前工作区。连接断开时可以重新读取原意图。已登记的未知结果会保留在对话中，恢复依据由现有原生会话层管理。

## 团队与画布

团队预览列出新角色、模型、提示词、建议的 Skills、节点绑定、交接和显式权限选择。配置从现有原生目录核验。用户确认后，Agent 记录和工作流通过一次事务写入，节点固定实际配置版本。实际启动仍走工作流的运行入口。

对开发、测试、审核团队，可选择已附加的工作区 Python 验证入口和期望 JSON。确定性交付 Gate 使用既有 Runtime。缺少独立验证入口时，反馈属于模型判断。创建和更新前可查看原图、目标图和新配置，普通画布提案沿用现有撤销。

## 诊断与授权修复

运行诊断通过已登记的 Run 和 Activation 读取错误、交接及可见回执。历史运行和源码上下文属于分析资料。修复预览显示原始证据、准确任务、受管 Agent 配置版本、工作目录及文件指纹。

执行修复需单独确认工作区写入。该入口需要已确认失败且进程结束的原运行、已保存的工作区读写 Agent 和本机非受保护 Git 分支。新修复运行使用独立的原生会话与启动意图，V2 Runtime 在发起调用前复核分支及 HEAD。结果可以对照已选文件的指纹。重新运行原工作流版本后，可把独立验证结果关联到修复记录。
