# DevFlower V2 工作台设计系统

左侧导航保留工作空间、工作流、会话和运行入口。编辑视图以画布为主，节点和连线检查器跟随当前选择。会话阅读与整次运行检查各有主工作区视图。长表单、阅读和终端有独立滚动区。共享主题为各视图提供语义 Token，布局与操作顺序独立于主题。

## 工作区与操作层级

- **设计工作流。** 保存、检查和启动在文档栏。添加节点与任务上下文靠近画布。可复用 Agent 配置由 Agent 管理维护，节点检查器负责选择已保存版本。节点形状、端口方向和连线标签表达类型及交接关系，运行状态沿用持久记录。
- **浏览会话。** 桌面保留列表与正文并排，过滤归列表，活动和浏览历史靠正文。别名、归档和格式等会话操作通过就近的展开入口提供。优先露出实际消息，正文保持可读行宽。窄窗口依次呈现列表和正文。选择其他工作区目的地后显示其内容，关闭会话视图后可回到先前图。
- **检查运行。** 整次运行检查使用宽视图呈现激活、事件、日志及原始证据，并保留当前运行状态和可用控制。可明确返回同一张运行图。选择图上的节点或连线时，右侧展示与当前激活对应的详情和真实交接。
- **退出和恢复。** Escape 先退出当前层级。切换视图保留草稿和视点，现有未保存保护仍生效。核验失败、待恢复、授权拒绝和只读状态在对应动作附近说明。

首轮以同主题对照了桌面完整工作区和画布下方联动。1440×900 的底部联动原型使图的可见高度缩至 220px，首条会话消息落到视口外。选定完整工作区承载正文与整次运行证据，保留图内上下文检查器。

## 主题与组件

| Token | 浅色 | 深色 |
|---|---|---|
| 应用底色 | `#EDF1F6` | `#10151F` |
| 工作表面 | `#FFFFFF` | `#171F2D` |
| 画布底色 | `#F4F7FB` | `#111926` |
| 边界 | `#D8E0EB` | `#303D50` |
| 主文字 / 次文字 | `#142238` / `#50617A` | `#E8EEF7` / `#AAB8CB` |
| 交互强调 | `#244BC6` | `#9AB0FF` |
| 成功 / 等待 / 错误 / 运行 | `#067452` / `#865008` / `#A32138` / `#244BC6` | `#73DDB2` / `#EFC584` / `#FF9BA9` / `#A7B9FF` |

中文用 Noto Sans SC 或系统回退。英文用 Inter 或系统无衬线回退。正文 14px，标签与证据摘要 12–13px，页面和面板标题 16–22px。代码、路径和终端用系统等宽字体。使用 4px 步进，常用间距 8/12/16/24px。桌面控件至少 32px，主要动作 36px。粗指针下增大点击区域。

按钮使用主动作、普通动作、工具图标和危险动作四种权重。Input、Select、Dropdown 使用一致边界和焦点。Tooltip 是补充说明，图标按钮保留可访问名称。Tabs 明确选中项。状态徽标同时呈现文字与标记。错误给出可执行的恢复入口，加载状态依据请求，运行状态依据真实事实。弹窗使用稳定焦点、Escape 及触发器焦点恢复。短窗口首先保留主动作和有效画布高度。

首屏从打开工作空间进入。空图提供创建或选择 Agent、添加节点和模板的就近动作。画布节点用图标、名称、类型、连接端口和真实状态形成层级。次级回执和原始身份逐步展开。
