# DevFlower 工作台界面规范

覆盖工作台、会话、AI 助手、画布、节点/连线检查器、模板、文件夹选择、运行与活动、终端、弹窗和保留的旧编辑器。运行授权、候选冻结、原生会话身份与安全门禁由原实现控制；视觉不能创造执行状态或成功裁决。

## 来源与采用范围

采用 [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) 的 DESIGN.md 分析，固定版本 `3b605329240ce735b510037cca322f1831fdd7f8`；MIT 通知见 `tools/studio/workbench_ui/vendor/awesome-design-md`。上游是设计参考文档合集，本机已安装同名适配 skill，构建不依赖它。

以 Vercel 的组件字号、中性表面与细边框为基础，吸收 Cursor/Claude 的阅读层级及 Miro 的画布分组。上游主要分析品牌网站；营销页面的巨大标题、96px 区段留白和品牌色不直接用于工作台。保持用户已有的 Sim 交互方向以及浅色、深色、系统主题。

## 统一视觉系统

共享色彩与尺度唯一入口为 `tools/studio/static/theme.css`。浅深色使用相同语义 token；`light-dark()` 随明确主题或系统配色工作，移除旧青色/紫色覆盖层。目标为支持该标准的现代浏览器，并用真实 Chromium 验证。

- 字体使用 Inter / Noto Sans SC / 系统无衬线回退；不下载专有字体。正文 14px，控件 12–13px，辅助说明 11px，标题 16–20px；代码保留等宽字体。
- 空间以 4px 为基准：8/12/16/24px；普通控件通常至少 32px，主要表单 36–40px。复选框保持独立尺寸。
- 控件圆角 6px，节点/面板 10–12px，对话输入区 14px。边框和表面对比优先，浮层才使用克制阴影。
- 状态同时使用文字、图标和颜色。失败、等待、取消、未知与通过不混用；读不到真实状态时显示待确认。
- 普通 hover/focus 反馈约 140ms。运行箭头只在真实持久化交接事件到达时短暂播放，保留 reduced-motion；不用无限动效伪装进度。

## 布局与阅读

顶部展示工作区、环境及主要运行操作；左侧管理工作流与原生会话；中央优先留给画布或阅读；右侧工具、模板、助手使用相同侧栏体系；底部活动默认收起。选中节点时不自动居中。

新手向导提供可关闭的下一步提示，展开后有完整可点击步骤。工具栏、向导、运行总览各表达一个职责，减少重复大色块和嵌套卡片。

助手采用固定头部、可滚动阅读区、底部输入区；新建、历史、设置就近可达。用户消息用轻表面区分，助手回答以正文为主；工具、原始身份按需展开。只展示接口明确提供的可见推理摘要。

数据交接先显示来源、内容与接收状态，再展开运行身份。下游节点以对话为主，实际请求与回执留在高级视图，仍绑定当前 run/activation/round。

表单区分标签、输入、说明与错误；弹窗标题和底部动作清楚，长内容可滚动。关闭视图不停止 Agent、不删除历史；危险操作继续说明准确范围与可恢复性。

## 核验与交付

从 JSX/CSS 源构建并验证生成字节。逐页覆盖浅/深色、窄屏、长标题/Markdown/代码/错误、键盘焦点、Escape、滚动与网络错误；复核画布拖动/选择/连线和会话身份。图片只证明实际场景，不能代替真实模型或独立审核。

Agent 操作、自动化检查与用户本人审美验收分别报告。全量回归、真实运行及同候选独立审核完成前，不称整个版本已验收或正式 Stable；历史失败保留。

## 本轮工作台重构：空间和交互预算

以Geist应用chrome为主参考，VS Code容器分工为布局依据，延续Sim画布操作。主工作区使用一条页签栏和一条画布标题工具栏；向导默认单行，展开不挤压画布。1280及以上可并列导航/编辑器/右面板；不足1180时右面板使用可关闭抽屉，760以下导航成为图标轨道和可展开抽屉。关闭右面板不进入全屏、不重置viewport。

常用任务和模型选择保持紧凑，错误与发送范围可解释、可定位，技术身份逐层展开。聊天只在接近底部时跟随新内容，空态不滚动，用户阅读历史时显示“新消息”入口。会话使用紧凑标题、状态和时间，次要节点归属通过可读提示提供，分组可折叠。重写studio.css作为工作台布局与组件视觉的统一最终样式入口，取代其旧配色覆盖；保留其他文件的行为/交互结构并清理本轮受影响的冲突规则。

验收包括1512×900、1280×800、952×756、700×900/560浅深/系统；主要操作可达、无横向溢出、空态标题与输入框可见、阅读不被抢滚动、弹层Escape/关闭不丢草稿/不停止运行，以及原异步身份/冻结运行隔离回归。
