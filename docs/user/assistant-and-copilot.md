# DevFlower 助手与工作流 Agent

右侧“工具 / 示例模板 / AI 助手”的 **AI 助手**页签打开 DevFlower 助手，画布“AI 配置”也是该页签的快捷入口，不再弹窗。切换页签保留对话、输入和生成状态。这是本软件自己的 Agent：拥有自己的对话、专用系统指令和画布工具，通过独立模型 API 推理。它不启动 Codex、Claude Code 或 Copilot CLI，也不是离线模型或自行训练的模型。

在助手中描述目标，例如“用 Copilot 分析任务，再让 Claude 复核遗漏”。允许发送当前对话与可见画布后，点击发送；经过本机严格校验的计划会更新草稿，可以撤销。继续聊天可以修改节点、连线和三个提示词。助手不会启动流程、读取工作区文件、授予权限或创建 PR。可生成顺序、只读并发/汇合、条件和有界循环（最多5轮、最多2层嵌套）。普通问答无需修改草稿。工作方式可选择自动、只问答或设计；只问答在模型接口关闭画布工具。每条回答标明普通回答或通过结构检查的画布提案，后者仍不代表实际任务已正确完成。

**模型设置**配置助手自己的服务地址、模型、推理强度和密钥，支持 Anthropic Messages 与 OpenAI 兼容 Chat Completions API。初次可引用操作者已经批准的模型接口；这只复用接口凭据，不复用任何编程 Agent 的会话、工具或权限。连接配置仅保存在本机私有存储，浏览器不会读回密钥；换服务地址必须填写该服务的密钥。更换连接会新开助手对话，旧历史保留。

**Copilot 是画布 Agent 的执行工具**。选择 Agent 节点，在基本设置中选择 GitHub Copilot，再选择当前账号目录中的模型。刷新会查询真实原生接口；登记不自动授予执行权，首次使用由现有执行准入完成连接检查。本机当前账号目录只返回 Auto，实际模型以每轮原生回执为准，不保证 Auto 固定使用某个模型。

本轮 Copilot 支持提供上下文的 Ask/Plan、明确 UUID 的原生创建/恢复、可见历史与工作流交接。没有开放文件工具、代码写入、原生交互终端、原生归档/删除或分叉；不能用提示词扩大权限。已有 Codex/Claude 执行器不受助手模型选择影响。

外部 Agent 可使用工作台已有受认证 HTTP 接口：`GET /api/devflower-agent/tools` 查询专用工具，`GET /api/config-assistant/schema` 获取严格计划合同，`POST /api/config-assistant/proposals` 提交草稿计划。应用仍经过同一校验与草稿版本检查。不要把工作台私有访问凭据发到聊天；当前没有宣称已提供 MCP 服务。

助手标题栏的“会话历史”支持搜索、切换、重命名、归档和移入回收站；归档与回收站均可恢复，不删除 Codex/Claude/Copilot 原生历史。正在生成或结果未确认的会话不能被归档/删除，应先停止或核实请求。设置连接会进入独立侧栏子页，返回即可继续聊天，不把大表单插在对话中。

Agent 模型从当前账号目录中选择后直接保存本次选择，不再出现“配置此模型 / 配置并选择”的第二次确认。选择模型不会改变工作区权限，也不会把目录发现当作真实调用成功；实际发送/运行仍执行原有授权、连接与占用检查，失败显示真实错误。目录来源、更新时间及可选手动检查收在“连接详情”中。

状态查询复用内容哈希，但每次检查 inode、大小、ctime、mtime、权限和链接信息，目录成员仍重新枚举；内容、配置或目录变化会使校验失效，缓存没有按时间跳过安全检查。助手模型目录短期缓存60秒，可显式刷新；会话切换不重复查询模型或重新推理。

打开文件夹时，左侧可选择“主文件夹 / 此电脑 / 挂载位置”，顶部路径栏可直接粘贴地址，也可以逐级点击面包屑和子文件夹，不需要进入高级设置。浏览和只读打开普通目录不会自动改变 Agent 的执行范围。受保护目录、符号链接、隐藏目录和系统伪文件系统不展示。目录属于运行工作台的那台电脑；远程浏览器不能把自己电脑的文件直接变成运行器目录。

助手的推理区只展示模型 API 明确返回的公开内容或摘要，标记来源；接口没有返回时会明确说明。不提取隐藏的 thinking/加密字段，也不重构完整思考链。DeepSeek OpenAI兼容接口返回的 reasoning_content 作为“模型公开推理”显示，最多8000字，经过脱敏；不会将其再发送给下游。中转站是否返回此字段取决于该接口，无法保证每个模型都有。

常用流程可以点击画布“收藏为模板”，填写名称和说明。右侧“示例模板 → 收藏”可再次使用，也可取消收藏、移入回收站及恢复。模板保存节点、连线和提示词；使用时新建可编辑草稿，不复制原生会话、附件引用、任务卡、运行回执或旧权限。模板仅存在本机工作台数据库和对应工作区，不自动上传云端。内置“综合协作：并行、审核与有界修订”组合两路只读分析、汇合、独立判断、条件和最多两轮修订，业务调用上界7次，默认总调用预算16次，为可能发生的连接诊断留出余量；运行预览会显示实际授权预算，不能靠缩减验证证明成功。

一轮完成后点击“下一任务”，或在“整轮对话”页点击“用此流程开始下一任务”。保留流程设计，填写新一轮目标，再按现有权限预览开始即可，不需要从头搭画布或重写所有节点提示词。每次开始都有新的 run；旧 run 的任务、冻结图、Agent 会话、回答、交接、轮次和运行事件仍留在历史。选过的原生已有会话仍须遵守同一身份和占用规则；默认新建会话节点在新 run 新建，不默认复制整段旧聊天。

“整轮对话”按时间展示你、本轮各 Agent 的回答、工具活动、交接和状态，支持切换历史、刷新和导出可见记录。未知时间明确标记，不猜测排序时间；原生记录缺失或超过展示预算会提示，完整原始记录仍留本机。导出的是脱敏的可见记录，不是认证文件、完整原生协议或交付批准。这里的消息来自真实持久记录，读取不会再次执行。

回答中的 Markdown 文件引用可以点击，经过工作区路径核对后选择“在 VS Code 打开”或“复制路径”。支持工作区内普通文件和行号；不开放任意命令链接、越界文件、私有凭据或运行回执。是否成功唤起 VS Code 取决于本机安装的 URI 处理器；也可以复制路径到自己的编辑器或文件管理器。软件不自动替换系统默认打开方式。
