# UI/UX Pro Max

Project adaptation of [UI/UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill/tree/6ae86f61f520d6ca229d2f40e070410638c908c5/.claude/skills/ui-ux-pro-max). Use the local reference and UX dataset for focused web and desktop workbench reviews.

1. Start from the user's task, actual screens, and DevFlower's design brief. Pick the affected interaction and the expected observable behavior.
2. Consult `references/quick-reference.md` and search `data/ux-guidelines.csv` for the matching outcome. Review accessibility and input feedback before layout, typography and motion.
3. Check keyboard access, visible focus, named controls, contrast in both themes, predictable dismissal and restoration, and short or narrow windows. Use compact desktop densities with larger touch targets on coarse pointers.
4. Establish shared semantic colors, typography and spacing before styling individual components. Validate the full interaction with a real browser and preserve the state, viewport and theme of each finding.

The project edition uses static reference data and standard text search.
